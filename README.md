# Aeroplane Ticket Booking Project

## Flight Service

This is the Flight service repo one of the microservices that my project has .

## About

This service roles and responsibilities are Add flights and remove flights and show flights with the filters like price based and source to destination etc .

## Technologies Used

- Express
- Mysql

## How to Run

1. Clone the repository.
2. Open the project in your IDE.
3. open terminal and run npm install this command install all the packages that are required to run the project
4. create dot env file and add the required things the sample dot env file is available for demo
5. open terminal and run the command npm start.
